# Project ALPHA

Clean working MVP starter for the hybrid investing dashboard.

## Setup

1. Copy `.env.example` to `.env.local`
2. Add your API keys
3. Run:

```bash
npm install
npm run dev
```

Open http://localhost:3000

## What is included

- Next.js app folder
- Project ALPHA dashboard
- Watchlist table
- AI score v1
- Finnhub quote API route
- FMP company profile API route
